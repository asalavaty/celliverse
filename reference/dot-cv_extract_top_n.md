# The n the user asked for, if they said one.

Only forms that NAME the quantity count. A bare number in "annotate C1"
or "top 5 markers of C3" must not become n, which is why there is no
bare-digit branch – the same trap Round LXXIV's \#11 detector had to be
narrowed for.

## Usage

``` r
.cv_extract_top_n(msg)
```
