# The delimiters marking a data region inside a prompt.

Kept identical to the strings Round LXIV chose for the annotation
prompt, so a model that has learned the convention from one prompt reads
the other the same way.

## Usage

``` r
CV_FENCE_BEGIN

CV_FENCE_END
```

## Format

An object of class `character` of length 1.

An object of class `character` of length 1.
